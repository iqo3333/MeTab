# MeTab Ver.9.3.5 兼容性规格表

MeTab 基于 **HTML5**、**CSS3**、**JavaScript (ES6+)** 及现代 Web API 构建，并使用部分高级 CSS 动画、布局和视觉特性。

Ver.9.3.5 在原有功能基础上，进一步完善了个性化壁纸、自定义快捷入口、音乐播放器、系统媒体控制及背景加载机制。

为了保证核心功能正常运行，并获得较完整的视觉效果和交互体验，建议使用以下浏览器版本。

## 2. 总体兼容性建议

### 2.1 桌面端

**推荐浏览器：**

- Google Chrome **100+**
- Microsoft Edge **100+**
- Mozilla Firefox **103+**
- Safari **15+**

**最低核心逻辑兼容版本：**

- Chrome **80+**
- Edge **80+**
- Firefox **74+**
- Safari **13.1+**

Chrome、Edge 和 Firefox 的最低版本主要受 `Optional Chaining (?.)` 影响；Safari 和 iOS Safari 则需要分别满足对应语法支持版本。

低于上述版本时，JavaScript 可能出现语法解析错误，导致主脚本无法正常执行。

### 2.2 移动端

**推荐浏览器：**

- iOS Safari **15+**
- Android Chrome **100+**

**最低核心逻辑兼容版本：**

- iOS Safari **13.4+**
- Android Chrome **80+**

移动端使用了以下技术：

- `touchstart`、`touchmove`、`touchend`
- Safari `gesturestart`
- `playsinline` 视频内联播放
- `env(safe-area-inset-*)` 安全区域适配
- 页面可见性检测及背景恢复

视频背景虽然已经配置静音、循环和内联播放，但是否能够自动播放，仍然取决于操作系统和浏览器的播放策略。

### 2.3 背景加载机制

Ver.9.3.5 对背景加载流程进行了进一步优化：

- 优先读取用户上次保存的背景设置。
- 没有保存记录时使用默认背景。
- 图片背景可以在主脚本执行前提前启动加载。
- 首次图片加载失败后自动尝试重新加载一次。
- 首次加载成功后不会执行额外的重试请求。
- 视频背景保留原有播放恢复机制，在页面重新获得可见性或网络恢复后尝试恢复播放。

其中，`fetchpriority` 属于浏览器加载优先级提示，不支持该属性的浏览器仍然可以正常加载图片，只是无法获得相同的加载优先级优化效果。

### 2.4 音乐播放器与系统媒体功能

MeTab 音乐播放器包含网页音频播放、本地音乐导入、在线音频缓存、歌词解析及系统媒体信息同步等功能。

主要依赖：

- `HTMLAudioElement`
- `IndexedDB`
- `Blob` / `URL.createObjectURL`
- `FileReader`
- `fetch`
- `TextDecoder`
- Media Session API
- MediaMetadata

其中，网页内音乐播放与系统媒体会话属于不同功能。

即使浏览器不支持 Media Session API，网页内的音乐播放、播放列表及基本控制仍可正常使用；系统锁屏控制、媒体封面和歌曲信息同步则可能无法完整呈现。

### 2.5 毛玻璃与高级视觉效果

MeTab 使用了多种现代 CSS 特性：

- `backdrop-filter`
- `-webkit-backdrop-filter`
- CSS Grid
- Transform / Transition
- `filter`
- `clamp()`
- `aspect-ratio`
- `env(safe-area-inset-*)`
- CSS 半透明背景及动画

其中，Firefox 对 `backdrop-filter` 的完整支持始于较新的版本，因此建议使用 **Firefox 103+**，以获得更完整的毛玻璃效果。

对于不支持部分 CSS 特性的浏览器，页面可能回退为普通半透明背景，或者出现布局、动画及安全区域显示差异。

### 2.6 不推荐使用的浏览器

以下浏览器版本不建议使用：

- Internet Explorer 全系列
- Chrome **< 80**
- Edge **< 80**
- Firefox **< 74**
- Safari **< 13.1**
- iOS Safari **< 13.4**
- Android Chrome **< 80**

这些版本可能无法解析当前项目使用的现代 JavaScript 语法，或无法完整支持部分核心功能。

即使部分 HTML 和 CSS 能够正常显示，也无法保证页面主逻辑、交互功能及个性化设置正常运行。
