# MeTab

**让每一次打开新标签页，都成为一次轻盈的开始。**

MeTab 是一款由 **林澈.LYC** 独立设计与开发的浏览器新标签页，致力于将简约美学、实用功能与个性化体验融为一体。

以清晰简洁的界面为基础，将时间、日期、搜索、快捷入口、壁纸与音乐播放器整合在同一个页面中。没有多余的信息干扰，也不需要复杂的操作，让每一次打开都自然、轻松。

MeTab 不只是一个新标签页，更是一个可以按照自己喜好打造的浏览器起点。

**简约而不简单，实用而有温度。**

[**在线体验 MeTab →**](https://tab.iqo3333.cn/)

[**项目介绍**](https://tab.iqo3333.cn/profile)

## ✦ 浏览器兼容性

MeTab 基于现代 Web 技术构建，部分视觉效果与交互功能依赖浏览器对相关 Web 标准的支持。

为获得更完整的视觉效果、更流畅的交互体验及更稳定的运行表现，建议使用以下版本或更新版本的浏览器：

| 浏览器 | 建议最低版本 |
|:--|:--:|
| Google Chrome | 100+ |
| Microsoft Edge | 100+ |
| Mozilla Firefox | 100+ |
| Safari | 15+ |
| iOS Safari | 15+ |
| Android Chrome | 100+ |

**注意事项：**
- 以上版本为建议的兼容性基准，并不代表所有功能均能在更早版本中正常运行。
- 不同浏览器及操作系统对部分 Web 功能的支持可能存在差异，实际体验以具体运行环境为准。
- 建议保持浏览器为最新稳定版本，以获得更好的兼容性、安全性与使用体验。
