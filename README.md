# MeTab - 简约美观，专注高效！

**让每一次打开新标签页，都成为一次轻盈的开始。**

MeTab 是一款由 **林澈.LYC** 独立设计与开发的浏览器新标签页，致力于将简约美学、实用功能与个性化体验融为一体。

以清晰简洁的界面为基础，将时间、日期、搜索、快捷入口、壁纸与音乐播放器整合在同一个页面中。没有多余的信息干扰，也不需要复杂的操作，让每一次打开都自然、轻松。

MeTab 不只是一个新标签页，更是一个可以按照自己喜好打造的浏览器起点。

**简约而不简单，实用而有温度。**

## ✦ 浏览器兼容性

MeTab 基于现代 Web 技术开发，并持续优化不同浏览器及设备上的显示效果与交互体验。

为确保页面功能稳定运行，并获得更完整的视觉表现，建议使用以下浏览器版本：

| 浏览器 | 推荐版本 |
|:--|:--:|
| Google Chrome | 100+ |
| Microsoft Edge | 100+ |
| Mozilla Firefox | 103+ |
| Safari | 15+ |
| iOS Safari | 15+ |
| Android Chrome | 100+ |

**兼容性说明：**
- 上述版本为推荐使用版本，并非项目实际运行的最低版本要求。
- 较早版本的浏览器可能无法完整支持部分视觉效果、动画及增强功能。
- 不同设备和浏览器的功能支持情况可能存在差异，具体表现以实际运行环境为准。
- 建议使用最新稳定版浏览器，以获得更好的兼容性与使用体验。
